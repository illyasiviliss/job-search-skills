# 能力族分类（用于总结能力画像）

目的：汇总能力时不要凭感觉列形容词，按「可被证据支撑」的族去归。每个族下面能填出证据才写，填不出就归到「缺口」。

## 通用族（数据 / 分析类岗位常用）

| 能力族 | 典型证据形态 |
|---|---|
| 数据处理与治理 | 清洗规模、准确率、对齐/去重/入库、多源整合 |
| 业务分析与洞察 | 漏斗/归因/AB、断点定位、指标拆解、结论被谁用了 |
| 建模与算法 | 模型类型、数据规模、效果指标、上线情况 |
| 可视化与 BI 交付 | 工具、看板受众、决策影响 |
| 工程与协作 | 语言/工具栈、版本控制、协作方式、自动化 |
| 行业 / 投资研究 | 研究框架、标的数量、报告去向（投委会/董事会） |
| 沟通与统筹 | 文案产出、活动统筹、跨部门协作 |
| 语言与证书 | 分数、等级、有效期 |

## 简历里没写但值得挖的

- **规模**：数据量、用户量、门店数、预算额、团队人数。数字是求职者最缺、也最能补的东西。
- **去向**：你的产出被谁用了（品牌经理？投委会？老板？），比做了什么更有说服力。
- **对比**：做之前 vs 做之后。
- **边界**：你负责的部分 vs 团队负责的部分 —— 背调时最容易翻车的地方，必须在母版里写清楚。

## 常见岗位关键词（对标 JD 时查）

- 数据分析：SQL、Python、指标体系、漏斗、留存、A/B、Dashboard、埋点、归因
- 数据科学：机器学习、特征工程、实验设计、统计推断、建模
- 投资研究：行研、尽调、财务模型、估值、赛道、投资备忘录、投委会
- 商业分析：BRD、业务指标、跨部门、项目管理、需求分析

> 关键词只是检索入口，对标后必须回到母版核对是否有真实证据，没有就不加。
