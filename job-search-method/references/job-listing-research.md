# 招聘信息检索：怎么找、怎么核、怎么落库

> 触发：用户说「帮我找 X 类岗位」「有什么实习机会」「某类公司招人吗」。
> 本文件只管**检索与落库**；值不值得投的判断仍走 03 偏好画像（交付物 → 雇主类型 → 岗位名称）。

## 1. 先把类别收窄，再动手（一次问清，不要猜）

- 拼接式短句会同时指向互不相干的赛道（例：「设计AI招聘人」→ AI+设计岗 / HR Tech 产品岗 / 设计岗 / 招聘 HR 岗，差一个词搜索结果完全不同）。**猜错一趟的返工成本远高于一次提问。**
- **用一次选项式提问问清**（多选 ＋ 固定选项 ＋ 末尾留一个自填项，让用户既能勾也能自己写）。选项**按「公司做什么」分**（做 AI 招聘产品的公司 / 该赛道的产品·agent 岗 / 设计岗 / 其他），**不要按岗位名称分**——岗位名会骗人。
- 只问一轮；拿到答复就开搜，不要连环追问。

## 2. 先确认哪条通道通，再决定证据等级

- **动手前先确认哪条检索通道真能用**，别默认「搜得到」。若在 Hermes 环境里：跑 `agent-reach doctor --json`，并用 `which agent-reach` 确认命令路径后再调用（别照抄 `conda run -n <env>` 前缀，抄错环境名会白费一轮）。某平台通道 `off` / 无 `active_backend` 就换零配置通道（网页搜索 ＋ 阅读器代理），**不要中断任务去装**；汇报时说明哪条没通，并给「装 / 登录」的选项让用户定。
- 内地岗位：网页搜索能覆盖，但源头几乎都是**第三方聚合页**（牛客、超级简历、鼠鼠求职、锦鲤求职、全职招聘网、牛企直聘）。
- 海外远程实习：多来自 Himalayas / Internshala / Jobrapido / 大学就业办等聚合站。
- **产出文件头写明本轮用了哪条通道**——来源可信度不同，日后复核要知道当时的证据等级。

## 3. 聚合页的三条坑（每条都踩过）

1. **薪资 / 届次 / 雇佣类型字段经常错位**：实习岗能被标成「134,000–201,000 HK$/年」「Permanent · Full time」。→ 只从聚合页取**职责与要求**；薪资、届次、地点一律回官网核，核不到就标 ⏳。
2. **截止日不清理**：过期条目照挂。→ 逐条核截止日；过期的不删，标 **🔴 已截止**留档，并在汇报里点明「同款大概率同期再开」是用户下一轮的盯点。
3. **地区 / 工作许可限制埋在正文**：远程实习常写 US only / India only / 需当地工作许可。→ 核实前**不进推荐表**，宁可标 ⏳。

## 4. 交表前把红旗过滤跑一遍，并说明过滤

- **先读偏好画像里的红线**（例如「纯猎头/招聘顾问岗，哪怕挂着 Data Analyst 招牌也跳过」这类）。命中的岗**一律不进推荐表**，但要在汇报里说一句「按你的红线已过滤这类岗」——让用户知道是主动筛掉的，不是漏了。
- 同理，把「公司是做这行的」与「岗位是干这行的」分开：在用户想进的赛道里，优先给**产品 / 数据 / 交付 / 工程**岗。

## 5. 落库 + 汇报格式

- 落一份**新编号**的赛道线索文件（见 SKILL.md 的前缀规则），文件头写：触发口径、检索日期、**通道实况**；表内每行＝公司 / 岗位 / 地点与形式 / 门槛关键词 / 状态标记（🟢现在开着 ／ 🟡等档期 ／ 🔴与红旗或档期冲突 ／ ⏳需核实）。
- 线索文件**只存事实**（链接、截止、门槛、薪资口径）；三档判断（值得优先 / 可以看看 / 跳过）写在聊天里，结论进 03。
- 同时在 03 观察表加一行（日期 / 场景 / 观察 / 强度）：**用户主动点名要搜某个赛道 = 中信号**（未升级为结论）。
- 汇报分三段：**现在就开着的 / 要等的 / 不进表的**，不要按公司名平铺；每条给一句「为什么是用户」，引用 JD 原词或用户自己的经历。收尾留**一个问题**决定下一步（当方向 → 进 JD 对照＋按该赛道重排简历；只找入口 → 只备该条投递材料）。

## 6. HR Tech / AI 招聘赛道的结构（快照，供快速定位）

- **内地买方**：北森（09669.HK；Mavens 平台 + AI 面试官；公开计划组 300 人 FDE 团队）、Moka（Moka AI / 招聘 Eva）、用友大易（YonGPT）、海纳AI、牛客、近屿智能；平台侧还有同道猎聘（6100.HK）、BOSS直聘、智联。岗位集中在**北京 / 上海 / 杭州 / 深圳**，校招入口多在自家招聘系统（如 `beisen.zhiye.com/campus/jobs`）。
- **香港本土几乎没有纯 HR tech 雇主在招**；可及的形态是**大企业 HR 部门里的 AI / 数字化岗**（例：Micro Connect 的 HR AI Agent 实习、HKEX 的 HR Tech & Analytics）。对在港读书的学生，这一层是身份加分最明显的地方。
- **海外 agentic recruiting 初创**（SCALIS、Noon、micro1、Mercor 等）多为远程或 US/UK 线下；Mercor 明确无远程。远程岗门槛普遍压在「会写代码」上 → 核实前不推荐。

## 7. 中小企业通道 ＋ 海投纪律（聚合站覆盖不到的那一层）

校招汇总表与聚合页只覆盖「有品牌、投得起校招广告」的公司。中小企业不发汇总、常年在招、岗位只挂官网／公众号／BOSS —— 而它们恰恰最适合练手（独立法人、独立 ATS、轮次少、反馈快）。

**四条通道**：

1. **工商数据反查（覆盖最广）** —— 企查查／爱企查／天眼查按「地区 ＋ 行业 ＋ 成立≥3 年 ＋ 注册资本 1000 万–5 亿」筛名单 → 逐个查官网 `/careers` 与公众号招聘页。产出「待查企业」表，逐条标「在招／不招／查不到」。
2. **园区与政府名录（最干净）** —— 前海、南山科技园、东莞松山湖、天河／黄埔、横琴的园区企业名录与官方公众号；人社局「青年就业见习基地」名单。名录自带招人属性，且常明确欢迎港澳青年。
3. **招聘平台反查（最快）** —— BOSS 直聘是中小公司主力（可直接与 HR／老板对话），筛「关键词 ＋ 城市 ＋ 融资阶段 A–C 轮 ＋ 规模 50–500 人」；实习僧补实习岗；前程无忧／智联补传统行业。**关键技巧：按「最新发布」排序，只看 14 天内的新岗** —— 中小公司的岗挂久了基本就是没在招。
4. **反向线索（最巧）** —— 从 JD 反查公司（搜关键词，记下反复出现却不在汇总表里的）；从人反查（职发处、校友群，中小公司爱在这里发独家）；从竞品反查（投了 A 就查 A 的服务商／供应商／竞品清单）。

**判断值不值得投四条**：① 有独立官网／招聘页（只有一条平台文本的跳过）；② JD 写清职责与汇报对象（模板化 → 大概率外包或中介）；③ 成立≥3 年、有真实产品（企查看主营与融资）；④ 面试流程清楚。

**海投纪律（不遵守会反噬）**：

- **别一天投完**：分 4 批、每批约 25 家，隔 2–3 天。短期集中多投会被 ATS 判「海投」静默降权。
- **同一集团／同一投递系统只投 1–2 个岗**，投前跑 3 问（见 `cv-master` 的「面试练手」一节）。
- 名单输出按**企业性质配额分批**（外企／央国企／民企／银行 各一批），比按公司名平铺更能看出哪一类有回音。
- 从汇总表筛出的「岗位」栏常常是一整包岗位大类（会混进土木、芯片这类无关项）→ **机器筛只出候选池，投前必须点进链接看具体 JD**，并苹告用户这一点，别让用户照着汇总栏投。
- **第三方汇总表（公众号／电商店卖的 xlsx ＋ 飞书或腾讯文档）只能当候选池与对照集，不当自采数据源**；项目类产出若声称「自建采集」，用别人整理好的表会让那句话变成假的。
